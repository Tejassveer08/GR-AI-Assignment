# E-Commerce Customer Segmentation & Churn Prediction

This project provides an interactive Streamlit app and supporting Jupyter Notebook for end-to-end customer segmentation and churn prediction on e-commerce data.

---

## Contents

- **app.py:** Main Streamlit web app for EDA, segmentation, churn prediction, and cost/ROI analysis.
- **customer_segmentation_churn_prediction.ipynb:** Notebooks for full ML workflow (data prep, feature engineering, model training).
- **artifacts/**: Generated models and preprocessing tools (created by notebook/training scripts).
- **ecommerce_customer_churn_dataset.csv:** Primary dataset for the app and notebook.
- **requirements.txt:** Python dependencies.

---

## Running the Streamlit App

### 1. Requirements

- Python 3.8+
- See `requirements.txt` for all dependencies:
  - `streamlit`, `pandas`, `numpy`, `scikit-learn`, `plotly`, `joblib`, etc.

Install required packages:
```bash
pip install -r requirements.txt
```

### 2. Prepare Artifacts

Before starting the app, the following files must exist (generated by the notebook):

- `artifacts/best_lightgbm.pkl` — Trained LightGBM model
- `artifacts/standard_scaler.pkl` — Feature scaler
- `artifacts/feature_columns.pkl` — List of input features
- `artifacts/model_ready_dataset.csv` — Preprocessed data with cluster labels, churn flags

If you haven't run the notebook yet, open `customer_segmentation_churn_prediction.ipynb` and execute all cells. This will create the required files in the `artifacts/` directory.

### 3. Launch the App

From the project root:

```bash
streamlit run app.py
```

The web interface will open in your browser.

## Using the Streamlit App

The app has four main tabs:

### 1. EDA

- Explore the raw dataset: preview rows, feature distributions, and missing value visualizations.

### 2. Segments

- View summary statistics and profiles for each discovered customer segment (churn rate, value, purchase history, etc.).
- Visualize churn by segment.

### 3. Prediction Sandbox

- Experiment with hypothetical customer profiles: adjust behavioral and demographic sliders, choose categorical groups.
- View a predicted churn probability and business recommendation (churn/retain) based on the trained model.

### 4. Cost & ROI Analysis

- Evaluate optimal thresholds to minimize business loss from churn using a cost-sensitive approach.
- Adjust costs for false positives/negatives and see expected impact on ROI.

## Jupyter Notebook (customer_segmentation_churn_prediction.ipynb)

- **Purpose**: Run full data pipeline: load data, clean/preprocess, exploratory analysis, feature engineering, clustering/segmentation, churn model training, and artifact export.
- **Tip**: Run all cells in order to create files `artifacts/best_lightgbm.pkl`, `artifacts/standard_scaler.pkl`, and others needed by the app.

## Dataset

- Input: `ecommerce_customer_churn_dataset.csv`
- Contains anonymized customer behavioral and transactional features, with churn flags.

## Troubleshooting

- If the app cannot find artifact files, ensure the notebook has run to completion and necessary files are present in the `artifacts/` directory.
- For library errors, confirm all requirements are installed in your current Python environment.
